适用范围：另一台 Windows 10/11 电脑，同一个 Fzdxkjy-web 校园网、10.20.21.2 门户。

1. 将压缩包复制到新电脑，完整解压后再操作，勿在压缩包内直接运行。
2. 在准备使用校园网的那个 Windows 账号下，双击 1-Prepare.cmd。看到 Step 1 complete 后关闭窗口。
3. 双击 2-SaveAccount.cmd，在本机窗口输入新电脑要使用的校园网账号和密码，点击“保存到本机”，保存成功后关闭窗口。
4. 双击 3-Enable.cmd，开启开机自动认证并立即检测一次。
5. 下次正常重启后检查是否直接联网。已联网时的检测成功，仅表示任务能运行，不代表真实登录已验证。

开关：3-Enable.cmd 开启，4-Disable.cmd 关闭。也可在 Windows 任务计划程序中启用/禁用 CampusNetworkAutoLogin。

程序安装到 %LOCALAPPDATA%\CampusNetworkAutoLogin。安装完成后，删除解压出来的安装包不影响运行。

密码由 Windows DPAPI 加密，只能由该电脑上的同一 Windows 用户读取。不要从旧电脑复制 credential.xml，也不要分享该文件。该安装包不含任何账号、密码、凭据文件或本机日志。

此方案不会替换学校后台的无感认证绑定，因此不需要转移唯一的设备名额。学校账号本身的同时在线数限制仍然适用。

当前方案分开执行准备、凭据保存与任务启用，不使用此前被卡巴斯基拦截的旧 Setup.ps1。如安全软件拦截，请保留具体提示，停止后续步骤；不要关闭防护或给 PowerShell 整体加白名单。

安装不修改 PowerShell 执行策略。如提示执行策略禁止、访问被拒绝或任务创建失败，请保留原始错误信息再排查。
